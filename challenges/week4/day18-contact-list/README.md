# Day 18 — Speed Pair: Same Prompt, 3 Stacks

**Time:** 90 min · Each person builds the same contact list app in a different stack.

Three sub-folders are scaffolded: `django-vue/`, `fastapi-react/`, `express-vanilla/`.
Each person picks one. Compare after.

## The prompt (all stacks)
- `GET /contacts` — list
- `GET /contacts/:id` — detail
- Frontend: search by name (filter as you type)

## After: 30-min retrospective
- Scaffolding time per stack?
- Easiest to wire frontend to backend?
- What's the same across all three stacks underneath the syntax?
