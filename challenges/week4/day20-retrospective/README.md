# Day 20 — Group Retrospective

**Time:** 60 min · Structured debrief. Prepare your notes before the call.

## Prepare (15 min solo)
Create `my-retro.md` in this folder:

```md
# My Retrospective

## Best challenge and why

## Worst challenge and what it revealed

## Pattern I now recognise on sight

## Biggest remaining gap

## Commitment for next sprint
```

## Group discussion (45 min)
1. Each person shares their best + worst
2. Everyone shares one pattern they now see
3. Plan next sprint: auth, databases, deployment, WebSockets?
4. Celebrate — 20 take-homes in 4 weeks
