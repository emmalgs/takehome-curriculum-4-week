# Day 02 — LRU Cache

**Time limit:** 45 minutes · **Stack:** Python · **Difficulty:** Medium

## The challenge

Implement an `LRUCache` class in `src/lru_cache.py`.

### Requirements
- `__init__(self, capacity: int)`
- `get(key: int) -> int` — return value or `-1` if not found
- `put(key: int, value: int)` — insert/update; evict LRU when at capacity
- Both operations O(1)
