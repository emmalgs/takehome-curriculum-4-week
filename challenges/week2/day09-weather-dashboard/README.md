# Day 09 — Fullstack: Weather Dashboard

**Time limit:** 90 minutes · **Stack:** FastAPI + Vue · **Difficulty:** Hard

## Setup
Get a free API key at https://openweathermap.org/api (takes ~10 min to activate).
Or set `USE_MOCK=true` in your .env to use mock data — document it in your README.

```bash
cd backend
cp .env.example .env   # add your API key or set USE_MOCK=true
pip install -r requirements.txt && uvicorn main:app --reload

cd frontend && npm install && npm run dev
```
